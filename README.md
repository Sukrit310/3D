# โมเดล 3D วัดพระศรีรัตนศาสดาราม (Wat Phra Kaew - Interactive 3D Model)

โปรเจกต์จำลองสถาปัตยกรรม 3 มิติของ **วัดพระศรีรัตนศาสดาราม (วัดพระแก้ว)** พัฒนาด้วย **Three.js (WebGL)** และ **Tailwind CSS** แบบไฟล์เดี่ยว (Self-contained HTML) พร้อมฟังก์ชันส่งออกไฟล์โมเดล 3D มาตรฐาน `.OBJ` สำหรับนำไปใช้งานต่อในโปรแกรม 3D เช่น Blender, Maya หรือ Unity

## องค์ประกอบสถาปัตยกรรมในโมเดล 3D
1. **พระอุโบสถ (Phra Ubosot)**: อาคารประธานประดิษฐานพระแก้วมรกต หลังคาลด 3 ชั้น มุงกระเบื้องเคลือบสีน้ำเงินและสีส้ม ขอบสีเขียว พร้อมช่อฟ้า ใบระกา หางหงส์ทองคำ เสาพาไล และซุ้มพัทธสีมา 8 ทิศ
2. **ฐานไพที (Upper Terrace)**:
   - **พระศรีรัตนเจดีย์ (Phra Si Rattana Chedi)**: เจดีย์ทรงระฆังคว่ำแบบลังกาขนาดใหญ่สีทองอร่ามทางทิศตะวันตก
   - **พระมณฑป (Phra Mondop)**: อาคารจัตุรมุขยอดมณฑป 7 ชั้นประดับกระจกสีเขียว-ทองตรงกลางฐานไพที
   - **ปราสาทพระเทพบิดร (Prasat Phra Thep Bidon)**: ปราสาทจัตุรมุขยอดพระปรางค์ทางทิศตะวันออก ขนาบด้วยพระสุวรรณเจดีย์คู่และยักษ์ทวารบาล
3. **พระอัษฎามหาเจดีย์ (Eight Prangs)**: พระปรางค์กระเบื้องเคลือบ 8 องค์ 8 สี เรียงรายตามแนวทิศตะวันออกหน้าวัด
4. **กลุ่มอาคารทิศเหนือ**: หอพระมณเฑียรธรรม พระวิหารยอด และหอพระนาก
5. **พระระเบียงคด กำแพงแก้ว และป้อมมุมกำแพง**: กำแพงใบเสมาสีขาวรอบวัด ซุ้มประตูยอดปรางค์บานประตูสีแดง และป้อมแปดเหลี่ยมมุมกำแพง

## วิธีใช้งาน
1. เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ได้ทันที (หรือเปิดผ่าน GitHub Pages)
2. ใช้เมาส์ **คลิกซ้ายลาก** เพื่อหมุนมุมมอง, **คลิกขวาลาก** เพื่อเลื่อนตำแหน่ง, และ **เลื่อนลูกกลิ้ง (Scroll)** เพื่อซูมเข้า-ออก
3. เลือกมุมกล้องลัดทั้ง 4 มุมตามภาพถ่ายจริง ปรับเวลาแสงเงา (เช้าตรู่, กลางวัน, ยามเย็น, กลางคืน) หรือคลิกปุ่ม **ดาวน์โหลด .OBJ** เพื่อบันทึกไฟล์ 3D Mesh
