# โมเดล 3D วัดพระศรีรัตนศาสดาราม & เกาะรัตนโกสินทร์ (Grand Masterpiece Edition)

โปรเจกต์จำลองสถาปัตยกรรมไทย 3 มิติความละเอียดสูงสุดของ **วัดพระศรีรัตนศาสดาราม (วัดพระแก้ว)** และบริบทรอบพระบรมมหาราชวัง พัฒนาด้วย **Three.js (WebGL)** แยกโครงสร้างโค้ดออกเป็นโมดูล (Multi-File Architecture) สำหรับจัดเก็บใน GitHub Repository ชื่อ `3D`

## รายละเอียดที่แก้ไขและอัปเกรดเพิ่มเติมล่าสุด
1. **แก้ไขปุ่มชมจุด "👹 ทศกัณฐ์ (เขียว) & สหัสเดชะ (ขาว)" (`yaksha_green_white`) ให้เด้งไปหน้ายักษ์โดยตรง**:
   - ปรับพิกัดกล้องจากเดิมที่อยู่ด้านหลังกำแพงพระระเบียงคด ให้มาตั้งอยู่ด้านหน้าซุ้มประตูฝั่งลานวัด (`camPos: [-19.8, 4.8, 1.5]`, `camTarget: [-31.2, 5.6, 1.5]`) หันหน้าเข้าหายักษ์ **ทศกัณฐ์ (กายสีเขียวมรกต)** และ **สหัสเดชะ (กายสีขาวบริสุทธิ์)** โดยตรง พร้อมเจาะช่องซุ้มประตูพระระเบียงคดให้เปิดโล่งเดินทะลุได้จริง ไม่ติดกำแพงวัดอีกต่อไป
2. **นำปุ่มมุมกล้องทั้ง 3 ปุ่มออกจากแผงควบคุมตามคำขอ**:
   - นำปุ่ม `🔔 มุมยักษ์เขียว & พระศรีรัตนเจดีย์` (`terrace_yaksha_chedi`) ออก
   - นำปุ่ม `3. มุมมองยอดปราสาทและพระเจดีย์` (`sunset_side`) ออก
   - นำปุ่ม `4. มุมมองระดับถนนหน้าป้อมกำแพงแก้ว` (`street_level`) ออก
3. **เพิ่มรายละเอียดความสมจริงทั่วทั้งโมเดล**:
   - **เรือด่วนเจ้าพระยาธงส้ม และ เรือหางยาวไทยประดับพวงมาลัยหัวเรือ (`createChaoPhrayaBoat`)**: แล่นไป-มาในแม่น้ำเจ้าพระยาหน้าท่าช้างวังหลวง
   - **กระถางธูปสามขาสำริดและเชิงเทียนบูชาพระรัตนตรัย (`createBronzeCenserAltar`)**: ประดิษฐานหน้าพระอุโบสถ หน้าพระวิหารยอด และบนฐานไพที
   - **อ่างบัวลายครามปลูกบัวหลวงบานสะพรั่ง, 70+ นักท่องเที่ยว/ไกด์ชูธงทัวร์/พระภิกษุ, รถเมล์ ขสมก. และรถตุ๊กตุ๊ก**
